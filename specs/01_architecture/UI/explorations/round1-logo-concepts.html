Dwelloot
Logo 概念对比

四个方向，全部用纯几何图元拼合（三角形 / 矩形 / 八边形 / 尖芒星）， 零曲线、零渐变、平涂 + 黑描边 + 硬阴影 —— 与 ui-exp01 分支现有的 marks.tsx 同一套语言。每个方向都同时解释产品含义与名字 Dwelloot 的关联。

0 · 这个 Logo 必须扛住的三件事

① 产品是什么

  • 恰好两个人的家务竞赛 app。记录家务 → 对方审批 → 得 Points → 一个周期里分高的人赢 Loot Box → 开出 Coins → Coins 换 Rewards。
  • Points 永不消费；Coins 是唯一可花的货币，只能靠赢得到。
  • 所以标志里必须有：家、二元对抗、战利品。

② 名字怎么拆

  • Dwell = 居住 / 家 → 屋顶、方盒、门。
  • Loot = 战利品 / 掉落 → 宝箱、开盖、金币、尖芒。
  • 两词共用中间的 “ll / oo” —— 双写字母本身就是“两个人”的暗示，方案 C 直接用这一点。

③ Neobrutalism 硬规则（来自 PDF）

  • 黑色无所畏惧：描边 + 硬投影都是纯黑 #000。
  • 投影有 X 和 Y、blur = 0、opacity = 100%。
  • 高饱和平涂，绝不用渐变。
  • 粗糙未加工的原始图形：矩形、三角、星形、多边形 —— “像 Windows 画图里拖出来的”。
  • 字体：无衬线 + 极粗（Archivo Black / Lexend Mega / Public Sans Bold）。

④ 项目自己已有的约束

  • 没有曲线：marks.tsx 里“硬币是八边形”。Logo 必须遵守，否则和 app 内图标是两种语言。
  • 色义已锁死：紫 = 你 绿 = 对手 黄 = Coins / 战利品 蓝 = Points。
  • 几何：--geometry-radius: 0（面）/ 8px（可按压控件）。Logo 走 0 圆角。

图形怎么拼：一个正方形（家）+ 一个三角形屋顶，屋顶沿正脊一刀劈成两半，左紫右绿；屋身正中开一道黄色投币口。三个图元，就这些。

产品含义：屋顶的两半 = 两个住在同一屋檐下的人，同一个家、两种颜色、共享一条脊。投币口把房子本身变成了那个 Loot Box —— 你们往里投的是家务，掉出来的是奖励。这正好是产品的核心循环。

和名字的关系：Dwell（屋形）与 loot（投币口 / 箱体）压在同一个形上，不是两个东西并排放。

图形怎么拼：矩形箱体 + 一条黄色包裹束带（直接呼应 BadgeMark 里的“首次兑换”包裹）+ 一个被顶歪 11° 的三角屋顶（它同时是箱盖）+ 一颗从缝里炸出来的八角尖芒星。

产品含义：捕捉的是动作发生的瞬间，而不是一个静态物件。盖子歪着 = 刚刚开箱；尖芒 = 奖励弹出。整个产品的情绪高点就在这一帧。

和名字的关系：屋顶 = Dwell，箱体 + 尖芒 = loot，两者是同一个盒子的上下半。掀开屋顶就是掀开宝箱 —— 名字的合成方式被画了出来。

图形怎么拼：把字母 D 去掉所有曲线，变成“矩形 + 尖角”的五边形。两个 D 背靠背镜像，共用中间一条黑缝，合起来正好闭成一个宝石 / 箱体轮廓；缝上压一枚黄色八边形硬币（与 CoinMark 同一个八边形）。

产品含义：两个人各占一半、背对背较劲，但只有合起来才是一个完整的形 —— 这就是“竞争性合作”的家庭。硬币压在接缝上：奖池属于中间，谁赢了才归谁。

和名字的关系：最直接 —— D for Dwelloot，而“双写”本身呼应 Dwell-loot 里那串双字母，也呼应“恰好两人”这条产品硬约束。

我的建议

首选 · C 双D

它是唯一同时满足「几何拼合」「产品功能含义」「与名字有联系」三条要求，并且在 24px 仍然清楚的方案。 “两个背靠背的 D 合成一个箱子、硬币压在接缝上”这句话本身就是产品说明书，答辩时一句话讲得完。 抽象度也让它不会和任何家务 / 房产 app 撞脸。

备选 · A 分脊屋

如果你更想让人第一眼就知道这是家务 app（对评委友好），选 A。它的语义最完整、最不会被误读， 代价是图形本身不够独特。B 太复杂、需要两套 mark 才能落地；D 会被读成图表工具。

选定后我会交付的整套 App 图标

  • favicon.svg（替换现有那个 728B 的旧箱子）+ favicon.ico 多尺寸 16/32/48
  • apple-touch-icon.png 180×180（含安全边距，iOS 会自己切圆角）
  • PWA icon-192 / icon-512 / maskable 512（安全区内缩 20%）+ manifest.webmanifest 片段
  • OG / 分享图 1200×630（Neobrutalism 版式：黄底 + 黑框 + wordmark）
  • wordmark lockup（横排 + 竖排 + 单色 + 深色）给 README 和答辩 PPT
  • 一份 ICONS.md，说明每个文件放哪、index.html 要加哪几行
